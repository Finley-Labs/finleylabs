# LAB 001 — Self-Healing Container Clusters

[LAB PLACEHOLDER]
This is a demonstration experiment for Finley Labs.

## Hypothesis
Locally run, quantized large language models (LLMs) can observe structural runtime trace logs and synthesize small, safe software patches to auto-correct microservice faults without restarting container pods.

## Status & Progression
We have created a local harness linking a running Go REST application container to a monitor service containing an Ollama node. When the REST container throws exceptions, the monitor feeds the trace to a customized agent that drafts a Go file correction, compiles it, and hot-swaps the binary target.
