# LAB 002 — Graph Neural Network Routing

[LAB PLACEHOLDER]
This is a demonstration experiment for Finley Labs.

## Hypothesis
Graph Neural Networks (GNNs) can scale coordination logic for cooperative pathfinding in dynamic grids faster than traditional A* or central server route reservations.

## Sandbox Results
We run simulations using PyTorch Geometric on dynamic graph grids. The GNN routing node handles agent conflict resolution locally, matching traditional solver speeds while computing moves 40% faster in high-agent densities.
